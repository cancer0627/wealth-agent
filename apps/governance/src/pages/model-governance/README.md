# model-governance（模型治理页面）

## Responsibility（职责）

负责：

- 展示治理事件并按事件类别筛选。
- 使用固定结构化样例发起确定性评测并展示汇总结果。
- 展示当前规则版本和原始问题不持久化的界面说明。

不负责：

- 不编辑治理规则、授权结果或审计事件。
- 不直接调用 Agent（智能体）、任务或业务能力，也不访问 SQLite（嵌入式关系数据库）。

## Boundary（边界）

- 只通过 `packages/api-client/` 调用后端 `governance` 公开接口。
- 页面只提交事件筛选条件和评测数据，治理判断、事件持久化与评分由后端负责。
- 当前是单一本地用户界面，不引入独立身份或令牌鉴权。

## State / Data Ownership（状态 / 数据所有权）

拥有：

- 当前事件类别、事件列表视图、评测结果、加载状态和页面错误等临时界面状态。

不拥有：

- 治理规则、授权决策、遥测与审计事件、评测记录和后端数据库。

## Navigation（导航）

- `implementation/`：页面实现。
- `contract/`：页面与后端之间的公开契约。

具体实现以源码为准。
