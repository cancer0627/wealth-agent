# chat（聊天页面）

## Responsibility（职责）

负责：

- 展示并发送多轮 Agent（智能体）会话消息。
- 创建、展示、编辑、删除、确认或丢弃 OCR（光学字符识别）草稿。
- 展示单条台账写入或产品资料更新的确认卡片，并传递确认或拒绝决定。

不负责：

- 不调用 Tool（工具）、生成任务计划或判断权限。
- 不直接写入业务数据库，也不提供备份恢复入口。

## Boundary（边界）

- 只通过 `packages/api-client/` 调用 `conversation` 和 `portfolio` 对应的后端接口。
- 页面不展示任务列表，也不提供暂停、恢复或取消任务操作。
- 待确认期间禁用普通消息输入，只允许确认、拒绝或重置会话。
- 备份恢复不会出现在本页面的 Agent 计划或工具中。

## State / Data Ownership（状态 / 数据所有权）

拥有：

- 当前输入、加载状态、页面错误和 `sessionStorage` 中的会话标识。

不拥有：

- 会话消息、OCR 草稿、内部任务、台账事实、治理结果和 Agent 决策。

## Navigation（导航）

- `implementation/`：页面实现。
- `contract/`：页面与后端之间的公开契约。

具体实现以源码为准。
