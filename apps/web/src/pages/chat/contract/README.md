# chat 页面 Contract（公开契约）

## Source of Truth（事实源）

页面使用的公开方法以 [`packages/api-client/src/index.ts`](../../../../../../packages/api-client/src/index.ts) 为准，
请求和响应结构以生成的 [`schema.d.ts`](../../../../../../packages/api-client/src/schema.d.ts) 为准。

页面只能依赖 API Client（接口客户端）公开导出的类型和方法，不应依赖后端能力的
`implementation/`。

## Behavioral Guarantees（行为保证）

- 页面复用 `sessionStorage` 中的会话标识；标识不存在或后端返回会话不存在时创建新会话。
- 发送消息时为每轮请求生成新的关联标识；页面展示后端返回的完整会话，不自行执行 Tool（工具）。
- 待确认写入只展示公开确认卡片，并向确认接口提交 `approve` 或 `reject`；卡片支持新增台账记录和产品资料更新。
- 待确认期间不发送普通消息；刷新页面后使用持久会话恢复同一张确认卡片。
- 草稿记录支持按行编辑和删除；编辑显式保存，删除前需要用户确认，操作成功后以服务端返回的会话刷新页面。
- 存在 OCR（光学字符识别）草稿时暂停消息发送和新图片上传；确认前读取当前台账版本，
  并提交匹配的草稿标识、明确确认和新的幂等键前缀。

## Preconditions（调用前提）

- 发送消息需要已加载会话和非空文本，文本长度受接口与页面的共同校验。
- 创建 OCR 草稿需要已加载会话和一个浏览器可读取的图片文件；记录编辑/删除、确认或丢弃需要当前草稿标识，记录编辑/删除还需要当前记录标识。
- 确认草稿需要能够读取当前台账版本；Agent 写入确认不由页面提交参数或台账版本。
