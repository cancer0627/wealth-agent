# reports（报表页面）

## Responsibility（职责）

负责：

- 展示产品目录、产品台账、估值、现金流和确定性收益报表。
- 发起产品删除和单产品模型分析。
- 展示最新模型分析结果与后端返回的数据质量警告。

不负责：

- 不计算收益、生成模型建议或保存业务事实。
- 不直接访问 SQLite（嵌入式关系数据库）或复制后端业务规则。

## Boundary（边界）

- 只通过 `packages/api-client/` 调用后端 `portfolio` 和 `analysis` 公开接口。
- 写入请求使用后端返回的台账版本，并为每次用户操作生成新的幂等键。
- 不依赖后端能力的 `implementation/`，也不自行判断业务写入是否合法。

## State / Data Ownership（状态 / 数据所有权）

拥有：

- 当前选择的产品、加载状态和页面错误等临时界面状态。

不拥有：

- 产品、估值、现金流、台账版本、确定性报表和模型分析记录。

## Navigation（导航）

- `implementation/`：页面实现。
- `contract/`：页面与后端之间的公开契约。

具体实现以源码为准。
