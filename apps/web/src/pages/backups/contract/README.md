# backups 页面 Contract（公开契约）

## Source of Truth（事实源）

页面使用的公开方法以 [`packages/api-client/src/index.ts`](../../../../../../packages/api-client/src/index.ts) 为准，
请求和响应结构以生成的 [`schema.d.ts`](../../../../../../packages/api-client/src/schema.d.ts) 为准。

页面只能依赖 API Client（接口客户端）公开导出的类型和方法，不应依赖后端能力的
`implementation/`。

## Behavioral Guarantees（行为保证）

- 页面刷新时并行读取当前台账版本与备份清单；创建成功后刷新两者。
- 只有清单中标记为有效的备份可进入恢复确认；确认文本必须与完整目标备份标识完全一致。
- 恢复请求同时提交目标备份标识、相同的确认备份标识和当前台账版本。
- 恢复成功后清除旧会话与活动任务的浏览器状态并刷新页面数据；失败时不执行这些清理。
- 页面不会触发自动分析、自动规划或其他业务写入。

## Preconditions（调用前提）

- 校验需要备份清单中的目标备份标识。
- 恢复需要已加载当前台账版本、有效目标备份和完全匹配的用户确认文本。
- 页面依赖本地后端与生成客户端的当前接口版本一致；后端负责备份完整性、版本和原子恢复校验。
