# backups（备份页面）

## Responsibility（职责）

负责：

- 展示业务台账备份清单及完整性状态。
- 发起备份创建与单个备份校验。
- 收集完整备份标识确认并发起台账恢复。

不负责：

- 不直接读取、复制或替换 SQLite（嵌入式关系数据库）文件。
- 不从 Agent（智能体）或自动任务触发恢复，也不在恢复后自动分析或规划。

## Boundary（边界）

- 只通过 `packages/api-client/` 调用后端 `portfolio` 和 `backup` 公开接口。
- 恢复请求必须携带当前台账版本及与目标完全一致的确认备份标识。
- 恢复成功后只清理本应用保存的旧会话和任务浏览器状态，再刷新台账版本与备份清单。

## State / Data Ownership（状态 / 数据所有权）

拥有：

- 当前恢复目标、用户输入的确认文本、校验结果、加载状态和页面提示。

不拥有：

- 业务台账、备份文件、备份清单、恢复前备份和后端恢复锁。

## Navigation（导航）

- `implementation/`：页面实现。
- `contract/`：页面与后端之间的公开契约。

具体实现以源码为准。
